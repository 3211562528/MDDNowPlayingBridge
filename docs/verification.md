# v1.3.1 验证范围

2026-10-29 在维护者 Mac 上安装并验证。实际 MDD 版本为 1.3.0.8。这些结果不是所有系统版本的兼容性保证。

- 发布构建与签名检查通过，十五项行为检查通过。
- 五次连续当前课程查询只发现一次端口、解析一次详情，强制刷新可用。
- 详情页存在但实际播放器关闭时，没有对应媒体会话。
- 打开原生播放器后，自动创建当前课程卡片并加载当前封面。
- 前台和后台的播放、暂停命令均改变实际 MDD 播放状态。同步通常需要约一秒。
- 稳定暂停后的连续系统下一项和上一项命令，确认前后各跳转 15 秒。
- 关闭实际播放器但保留详情页后，卡片清空。连续五次系统查询没有重新出现。重新打开播放器后再次创建。
- 验证结束时恢复暂停。未将命令发送成功当作播放器动作成功。

精确跳转检查必须等待播放器加载完成。MDD 日志中第一次 seek 的 prePos 是上次跳转目标，并非实时播放位置，不能用第一次差值推断跳转长度。

AirPods 实体按键未重新实测，已验证的是同一系统媒体命令路由。当前版的小图标没有重新截图验证，保留了此前验证有效的应用身份和本地图标。

性能改动包括复用端口、减少重复详情解析、保留当前封面而非多图缓存、以文件事件替代日志轮询，以及没有实际播放器时取消周期查询。没有在公开版本上重新进行完整跨版本 A/B 性能比较，因此这里不声明固定 CPU 或内存节省比例。
